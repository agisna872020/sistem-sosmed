# Skill dan SOP agent

Taruh skill atau SOP terkait produk dan proses kerja Luevora di sini. Untuk skill berformat direktori, gunakan:

```text
nama-skill/
  SKILL.md
  references/     opsional
  scripts/        opsional
```

Tuliskan kapan skill digunakan dan langkah kerjanya. Agent membaca skill yang relevan ketika mengerjakan tugas. Folder ini menyimpan skill proyek; pemasangan skill ke aplikasi agent dilakukan terpisah jika diperlukan. Jangan memasukkan kredensial ke skill.
