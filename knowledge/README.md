# Knowledge Luevora

Folder ini adalah sumber informasi untuk agent. Pemilik bisnis akan mengisi dokumen dan menambahkan skill di sini.

- `products/luevora.md`: **sumber utama detail produk Luevora**, disediakan oleh pemilik bisnis pada 2026-11-07. Wajib dibaca ulang setiap task yang membutuhkan informasi produk, termasuk batasan klaim pada bagian 10.
- `brand/profile.md`: identitas, target audiens, gaya bahasa, dan panduan visual.
- `products/_template.md`: salin menjadi satu dokumen per produk.
- `assets/`: aset brand yang digunakan ulang, termasuk logo, foto asli, dan font berlisensi.
- `references/`: contoh konten, riset, dan insight akun.
- `skills/`: skill atau SOP kerja tambahan.

Informasi yang belum tersedia dibiarkan kosong. Cantumkan tanggal pembaruan dan sumber untuk harga, klaim produk, serta promosi. Instruksi terbaru dari pemilik bisnis menjadi acuan jika dokumen berbeda. Jangan simpan API key di knowledge.

Panduan tema postingan berada di `../tema-konten/README.md`. Baca instruksi dan detail tema yang dipilih saat membuat konten.
